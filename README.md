# Peace Racer (demo)

Play it in the browser: https://tumuworks.github.io/peace-racer-demo/

The Attai and the Pacesetter against the clock on Kumotori Pass, downhill and
uphill. Arrow keys or WASD, Shift or Space for the handbrake, Esc to
pause; a gamepad or a phone (sideways) works too.

This repo only holds the built game.
